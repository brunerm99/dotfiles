# Configuration workflow

For this Omarchy machine, keep configuration changes in this repository as well
as their active locations under `~/.config`. Commit and push completed changes
to the `omarchy` branch. Check existing work before editing or committing.

Live configuration copies are under `omarchy/config/`, mirroring `~/.config/`.
Theme files remain under `omarchy/workbench-dark/` and `omarchy/workbench-light/`.
Do not commit credentials, OAuth tokens, browser profiles, core dumps, or backups.
